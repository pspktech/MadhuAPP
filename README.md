# MadhuAPP 🚀

A modern Full-Stack Mobile Application template built with **Expo (React Native)**, **Express**, and **tRPC**. This project features a fully type-safe API, a beautiful UI powered by NativeWind (Tailwind CSS), and a MySQL database managed by Drizzle ORM.

## 🛠️ Tech Stack

- **Frontend:** Expo, React Native, React, NativeWind (Tailwind CSS), Expo Router
- **Backend:** Node.js, Express, tRPC
- **Database:** MySQL, Drizzle ORM
- **Testing:** Vitest
- **Package Manager:** pnpm

## 📁 Folder Structure

- `app/` - Expo Router screens and navigation
- `server/` - Backend API, tRPC routers, and database logic
- `components/` - Reusable UI components
- `drizzle/` - Database schema and migrations
- `hooks/` - Custom React hooks
- `lib/` - Utility functions and configurations
- `assets/` - Static files (images, fonts, etc.)
- `tests/` - Unit and integration tests
